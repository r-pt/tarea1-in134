1. ¿Por qué si los pixeles de la imagen son números enteros ∈ [0, 255], utilizamos el tipo de dato unsigned char?
Porque con el unsigned char es posible asignar los valores e 0 al 255 con poca memoria, entonces es conveniente en casos como estos necesitan un rango "pequeño"

2. ¿Cuáles serían las diferencias entre usar unsigned int versus unsigned char? Responder cuantitativamente para una imagen RGB de dimensiones (N,N,3).
El unsigned char usa menos espacio en la memoria (1 byte) pero solo son numeros entre el 0 y 255, mientras que el unsigned int usa más espacio en la memoria (4 bytes), para nuestro caso de imagenes de dimensiones (N,N,3) nos es conveniente el unsigned char pues no necesitamos un rango tan grande, seria desperdiciar espacio (x4 de lo que usariamos usando el estándar )
